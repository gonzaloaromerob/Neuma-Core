# Próximos casos reales

Para validar NEUMA 3.0 más allá del piloto inicial, priorizar casos con diversidad de patrón y riesgo controlado:

1. **Investigación:** fuente externa/Drive → evidencia → síntesis → decisión o recomendación trazable.
2. **Reunión:** notas autorizadas → decisiones/riesgos/tareas → seguimiento en Notion.
3. **GitHub:** issue o cambio metodológico → PR → revisión → Gate → merge/verificación.
4. **Documento:** original en Drive/SharePoint → análisis → artefacto derivado sin alterar la fuente.
5. **Operación multiapp:** evento en un sistema → actualización idempotente en otro → verificación y compensación.

Cada caso debe registrar fricción, errores evitados, verificaciones, Gates y aprendizaje para contrastar las métricas propuestas.
