# Modelo mínimo de trazabilidad

Para una operación material, registrar cuando sea pertinente:

- **Origen:** sistema, objeto y versión/fecha relevante.
- **Autoridad:** System of Record y clasificación de sensibilidad.
- **Transformación:** qué se extrajo, resumió, convirtió o decidió.
- **Decisión:** recomendación, Gate y autorización cuando aplique.
- **Destino:** sistema y objeto exacto modificado o creado.
- **Resultado:** identificador, commit, URL o estado devuelto.
- **Verificación:** evidencia de la postcondición.
- **Efectos secundarios:** eventos externos observados.
- **Compensación:** mecanismo para corregir un derivado o fallo parcial.

La trazabilidad debe ser suficiente para reconstruir la operación sin convertir cada acción trivial en burocracia documental.
