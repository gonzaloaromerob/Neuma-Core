# Architecture

Arquitectura conceptual y operativa de NEUMA.

Este directorio debe contener modelos de componentes, límites de autoridad, flujos humano–IA, integración entre sistemas y decisiones arquitectónicas complementarias a los ADR de `decisions/`.

## Reglas
- describir estado actual y estado objetivo por separado;
- distinguir decisiones aprobadas de hipótesis;
- enlazar ADR relevantes;
- evitar secretos, credenciales y datos sensibles.
