# Skills

Especificaciones, documentación y artefactos versionables de skills relacionadas con NEUMA.

Una skill publicada o instalada puede tener un mecanismo de distribución distinto. Este directorio funciona como fuente versionada cuando se decida conservar aquí su especificación canónica o una versión exportable.

Toda capacidad documentada debe distinguir entre expuesta, autorizada y empíricamente validada.
