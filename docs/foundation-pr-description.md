# Texto base del PR Foundation

## Qué cambia
Establece una Foundation pública y revisable para NEUMA 3.0: núcleo, método, gobierno, Operations, privacidad, evidencia, seguridad, métricas y aprendizaje.

## Qué no cambia
No modifica el website archivado, no incorpora la fuente estratégica interna de Drive, no crea una release y no declara NEUMA 3.0 estable.

## Evidencia
Incluye un primer caso real gobernado donde una fuente interna fue preservada en Drive, registrada en Notion y no copiada a GitHub.

## Riesgo
El principal riesgo es canonizar demasiada documentación demasiado pronto. Se mitiga mediante estado Foundation, revisión crítica, preguntas abiertas y compromiso de consolidación basada en uso.

## Gate
El PR puede abrirse en draft; el merge requiere aprobación humana explícita nivel C.
