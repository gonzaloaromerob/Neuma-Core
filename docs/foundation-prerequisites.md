# Prerrequisitos antes de canonizar Foundation

- Rama aislada y basada en `main` actual.
- Diff completo revisado.
- Sin contenido interno copiado desde la fuente estratégica de Drive.
- Documentos explícitamente marcados como mínimos, Foundation, hipótesis o preguntas abiertas cuando corresponde.
- Separación entre NEUMA metodológico y NEUMA Operations.
- Sin declaración de NEUMA 3.0 como versión estable o release candidate.
- Revisión crítica incluida en el propio conjunto.
- Merge sujeto a Decision Gate C explícito.

Si alguno de estos puntos deja de cumplirse antes del merge, el Gate debe reabrirse y el cambio debe corregirse antes de promoverse a `main`.
