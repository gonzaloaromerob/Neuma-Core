# Criterios de aceptación de Foundation

Antes del merge, comprobar:

- [x] La rama parte del `main` canónico actual.
- [x] No está por detrás de `main` al cierre de preparación.
- [x] La fuente estratégica real permanece fuera de GitHub.
- [x] Existe clasificación y registro de la evidencia en Notion.
- [x] El núcleo diferencia principios, hipótesis, capacidades y preguntas abiertas.
- [x] Existe revisión crítica y registro de riesgos.
- [x] Existe política de privacidad, evidencia y seguridad.
- [x] Existe mapa de fuentes de verdad y gobierno de canonización.
- [x] El conjunto no se presenta como release candidate ni versión final.
- [ ] Gate C humano aprobado para merge.
- [ ] `main` verificado después del merge.

Los dos últimos puntos solo pueden completarse durante y después de la decisión de promoción.
