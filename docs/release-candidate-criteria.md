# Criterios para NEUMA 3.0 Release Candidate

NEUMA 3.0 puede considerarse `release candidate` cuando:

1. el núcleo conceptual no presente contradicciones materiales conocidas;
2. Constitución Operativa, manifiesto, glosario y arquitectura utilicen terminología coherente;
3. las principales decisiones de diseño estén registradas mediante ADR;
4. exista evidencia de aplicación en varios casos reales, no solo pilotos ficticios;
5. las limitaciones y preguntas abiertas estén documentadas;
6. NEUMA Operations tenga controles de seguridad, trazabilidad e idempotencia suficientemente probados para sus flujos principales;
7. exista una revisión crítica que intente refutar o encontrar fallas en el marco;
8. los materiales públicos no expongan información interna o sensible por arrastre documental.

Cumplir estos criterios no convierte el marco en definitivo; solo indica suficiente coherencia para una revisión de versión formal.
