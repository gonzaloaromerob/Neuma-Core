# Lección aprendida 002 — acceso no equivale a publicación

## Observación
En el primer caso real, NEUMA Operations pudo localizar y leer una fuente estratégica interna almacenada en Google Drive.

## Riesgo
Copiar automáticamente esa fuente o sus detalles a un repositorio GitHub público habría confundido capacidad técnica con autorización y habría roto la separación entre evidencia y conocimiento canónico.

## Control aplicado
- conservar el original en Drive;
- clasificar la evidencia como interna;
- registrar únicamente referencia y contexto operativo en Notion;
- derivar a GitHub solo reglas metodológicas deliberadamente publicables.

## Generalización
La automatización correcta puede consistir precisamente en **no mover** información cuando la autoridad, sensibilidad o necesidad no lo justifican.
