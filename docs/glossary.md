# Glosario mínimo NEUMA

**Agencia humana:** capacidad y responsabilidad de la persona para comprender, decidir, autorizar y responder por decisiones materiales.

**Artefacto canónico:** versión autoritativa y deliberadamente mantenida de un objeto versionable.

**Compensación:** acción que restaura o corrige un derivado cuando una operación distribuida no puede revertirse de forma transaccional.

**Decision Gate:** punto de control que determina si una acción puede ejecutarse autónomamente o requiere decisión humana explícita.

**Evidencia:** fuente u objeto que soporta un análisis, hallazgo o decisión y cuya procedencia debe poder reconstruirse.

**NEUMA Operations:** capa operativa para ejecutar flujos seguros y verificables entre ChatGPT y sistemas conectados.

**Proyección:** representación derivada y mínima de un objeto canónico en otro sistema; no constituye una segunda fuente de verdad.

**System of Record (SoR):** sistema designado como autoridad para un tipo de objeto.

**Trazabilidad:** capacidad de reconstruir origen, transformación, decisión, acción, destino y verificación de un flujo.

**Verificación:** comprobación de que una afirmación o postcondición coincide con evidencia observable suficiente para el nivel de riesgo.
