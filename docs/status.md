# Estado de NEUMA 3.0

## Estable
- Secuencia NEUMA: verdad → claridad → decisión → acción.
- Agencia y responsabilidad humana.
- Distinción entre hechos, supuestos, inferencias, incertidumbres y recomendaciones.
- Proporcionalidad de rigor y verificación.
- Arquitectura federada de conocimiento con System of Record explícito.

## Validado operacionalmente
- Lectura/escritura/verificación controlada en Notion y GitHub para los patrones documentados.
- Proyección unidireccional GitHub → Notion con idempotencia y compensación en piloto.
- Decision Gates para separar autonomía operativa de decisiones materiales.
- Preservación de evidencia en Drive mientras se deriva conocimiento público sin copiar la fuente interna.

## Hipótesis de trabajo
- La calidad de NEUMA Operations se mide mejor por trazabilidad, recuperabilidad y reducción de errores que por cobertura de endpoints.
- Una arquitectura federada aporta más control y portabilidad que una sincronización total entre herramientas.

## Pendiente
- Revisar y canonizar selectivamente artefactos históricos de NEUMA.
- Probar métricas de madurez en más casos reales.
- Evaluar controles administrativos de GitHub cuando los conectores los expongan.
- Desarrollar materiales pedagógicos y casos reproducibles a partir del núcleo estable.
