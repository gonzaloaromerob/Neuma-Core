# Alineación con el gobierno interno de NEUMA 3.0

Fecha de corte: 2026-08-18.

Este repositorio no es la fuente de verdad de los documentos rectores internos. El corpus rector reside en SharePoint y fue consolidado en v1.1 con:

- `NEUMA 3.0 - Manual de Gobierno.DocX`;
- `NEUMA 3.0 - Anexos Operativos.DocX`;
- `NEUMA - Prompts.DocX` (continuidad consolidada);
- `NEUMA - Runbook Integraciones.DocX`;
- `NEUMA 3.0 - Mapa Maestro Documental.DocX`.

## Decisiones reflejadas aquí

1. NEUMA 3.0 se define como marco metodológico de gobierno para la colaboración humano–IA.
2. Secuencia: **verdad → claridad → decisión → acción**, con verificación transversal.
3. La agencia y responsabilidad final permanecen en el humano.
4. La autonomía operativa se gobierna mediante niveles A/B/C y Human Decision Gates.
5. Arquitectura federada: SharePoint = corpus rector interno; GitHub = conocimiento deliberadamente versionable/publicable; Notion = capa operativa; repositorios de origen = evidencias/originales cuando corresponda.
6. Las proyecciones entre sistemas deben ser idempotentes y respetar un System of Record por objeto.
7. `OLD/` y artefactos `superseded` son históricos, no normativos por defecto.
8. NEUMA no se presume eficaz por definición; debe distinguirse implementación, percepción y evidencia real de eficacia.
9. Publicación, licencia, marca, derecho de autor y legado son capas distintas y requieren Gates específicos antes de actos externos.

## Regla

Una síntesis de GitHub no sustituye automáticamente el documento interno del que deriva. Ante conflicto, debe consultarse el corpus rector y la decisión metodológica más reciente aplicable.
