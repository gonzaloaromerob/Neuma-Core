# Decisión pendiente — promoción de NEUMA 3.0 Foundation

## Recomendación
Promover el contenido de `develop/neuma-3-foundation` a `main` mediante squash merge después de revisión del PR.

## Fundamento
El conjunto crea una base coherente, explícitamente no definitiva, mantiene fuentes internas fuera del repositorio público e incorpora revisión crítica, límites y preguntas abiertas.

## Mejor objeción
El conjunto es amplio y puede introducir demasiados documentos antes de que exista suficiente evidencia de uso. La mitigación es tratarlo como **Foundation**, no como release candidate, y consolidar o eliminar artefactos a partir de experiencia real.

## Gate
El merge es nivel C porque convierte estos documentos en canon público inicial de NEUMA 3.0. Requiere aprobación humana explícita después de revisar el PR.
