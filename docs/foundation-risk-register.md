# Riesgos de NEUMA 3.0 Foundation

| Riesgo | Evaluación | Tratamiento actual |
|---|---|---|
| Fragmentación documental | Media | Índice, mapa de artefactos y consolidación futura basada en uso |
| Canonización prematura | Media | Foundation explícita; no declarar versión estable ni RC |
| Publicación accidental de información interna | Alta | Frontera de privacidad, clasificación y caso real sin copia de fuente |
| Sobreajuste a proveedores actuales | Media | Separar principios de capacidades y mantener preguntas abiertas |
| Exceso de Gates | Media | Proporcionalidad A/B/C y métrica de falsos escalalamientos |
| Dependencia acrítica de recomendaciones IA | Alta | Agencia humana y Gates C explícitos |
| Complejidad superior al valor | Media | Métricas, antipatrones y revisión operacional periódica |

Este registro debe revisarse con evidencia de uso; no representa una evaluación cuantitativa formal.
