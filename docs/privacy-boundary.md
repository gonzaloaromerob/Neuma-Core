# Frontera de privacidad y separación de contextos

## Principio
NEUMA debe evitar trasladar información sensible entre proyectos, clientes o contextos solo porque esté técnicamente disponible.

## Reglas
- Utilizar únicamente la información necesaria para el objetivo actual.
- No incorporar automáticamente a Neuma-Core datos jurídicos, familiares, profesionales o de clientes.
- Preferir ejemplos ficticios o anonimizados para documentación pública.
- Mantener documentos sensibles en el sistema autorizado de origen.
- Una síntesis publicable debe eliminar detalles que permitan reconstruir información privada innecesaria.
- Las relaciones entre sistemas deben transportar la mínima información necesaria para el propósito operacional.

## Criterio
La trazabilidad no exige centralización. Puede preservarse mediante referencias controladas sin replicar el contenido sensible.
