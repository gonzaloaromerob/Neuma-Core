# Skills NEUMA

Este directorio documenta la función y el gobierno de las skills relacionadas con NEUMA.

## NEUMA Operations
NEUMA Operations es la capa operativa para ejecutar flujos seguros y verificables entre ChatGPT y sistemas conectados. Su distribución ejecutable puede mantenerse en el runtime de ChatGPT cuando ese sea el System of Record efectivo; este repositorio conserva especificaciones públicas, decisiones y documentación estable cuando aporten trazabilidad o reutilización.

## Regla de publicación
No copiar automáticamente credenciales, configuración privada, identificadores sensibles ni artefactos internos de runtime. Promover únicamente documentación deliberadamente publicable y versionable.
