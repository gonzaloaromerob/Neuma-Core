# Documentation

Documentación consolidada **vigente** de NEUMA bajo control Git.

Los originales documentales cuyo System of Record sea SharePoint, Drive u otro repositorio permanecen allí. Este directorio sólo conserva documentos que siguen aportando una función activa: release vigente, migración/compatibilidad, conformance aplicable y change notes actuales.

Los documentos pre-release, RC o change notes superseded no se mantienen como archivos muertos en `main`: Git conserva su historia. Las evidencias de pilotos se conservan sólo mientras sigan justificando el estado vigente de módulos o controles.
