# Mapa de fuentes de verdad NEUMA

## Objetivo
Hacer explícita la autoridad de cada categoría de información y evitar que accesibilidad técnica se confunda con autoridad documental.

| Categoría | Fuente de verdad | Observación |
|---|---|---|
| Núcleo conceptual NEUMA 3.0 | Neuma-Core | Markdown versionado y revisado |
| Decisiones arquitectónicas | Neuma-Core / decisions | ADR |
| Arquitectura y gobierno | Neuma-Core / architecture | Versionable y publicable |
| NEUMA Operations ejecutable | Runtime/skill instalada | GitHub conserva documentación pública estable |
| Proyectos, tareas, riesgos y gates | Notion | Capa operativa y relacional |
| Evidencias y originales | Repositorio documental de origen | Drive, SharePoint u otro sistema autorizado |
| Sitio web productivo | Repositorio/hosting web separado | No forma parte de Neuma-Core |
| Material histórico | Neuma-Core / archive o repositorio de origen | No implica vigencia |

## Regla de prevalencia
Ante conflicto entre una proyección y su fuente de verdad, prevalece la fuente designada. La discrepancia se registra y se compensa el derivado; no se altera el canónico para acomodar una copia.

## Revisión
Este mapa debe actualizarse cuando cambie la autoridad de una categoría, se incorpore un nuevo sistema o un artefacto pase de experimental a canónico.
