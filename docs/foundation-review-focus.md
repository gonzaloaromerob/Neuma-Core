# Focos de revisión del PR Foundation

La revisión humana no necesita leer todos los documentos con igual profundidad. Priorizar:

1. `neuma-3.0-core.md` — si representa correctamente el núcleo.
2. `constitution-operational-minimum.md` — si los límites de autoridad son apropiados.
3. `human-ai-contract.md` — si la distribución de responsabilidades es equilibrada.
4. `minimum-method.md` — si el método es práctico y no burocrático.
5. `knowledge-governance.md` y `source-of-truth-map.md` — si la arquitectura federada es correcta.
6. `decision-gates.md` y `automation-boundaries.md` — si autonomía/control están bien calibrados.
7. `foundation-review.md` y `foundation-risk-register.md` — objeciones y riesgos.

El resto funciona principalmente como soporte, operacionalización, trazabilidad o evolución.
