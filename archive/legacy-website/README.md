# Legacy website archive

Copia histórica del sitio web estático que ocupaba la raíz del antiguo repositorio `Neuma-WebSite`.

Se preserva para trazabilidad y referencia histórica. **No es el sitio productivo actual de NEUMA y no debe tratarse como fuente canónica de la metodología.**

Los archivos HTML/CSS originales permanecen disponibles en el historial Git de `main` previo a la reestructuración. Esta carpeta marca explícitamente su nueva clasificación como legado.
