# Alcance de NEUMA 3.0 Foundation

## Incluye
- núcleo conceptual y operativo mínimo;
- gobierno del conocimiento y fuentes de verdad;
- límites de privacidad, evidencia y seguridad;
- modelo de colaboración humano–IA;
- Decision Gates y límites de automatización;
- patrones multiapp validados;
- métricas, lecciones y preguntas abiertas.

## No incluye todavía
- una demostración científica de superioridad frente a otros marcos;
- una versión final de materiales comerciales o pedagógicos;
- especificaciones exhaustivas para todos los conectores;
- automatización productiva generalizada;
- una ontología completa del conocimiento NEUMA;
- compromiso de compatibilidad permanente con proveedores concretos.

## Interpretación
Foundation significa base coherente para seguir validando y refinando; no significa versión terminada.
